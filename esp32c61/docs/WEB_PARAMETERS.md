# 网页参数配置与图像显示设置

## 入口与更新要求

ESP32 控制台 → **超声参数控制 → 高级参数配置**，或打开 `http://192.168.3.27/parameters`。
硬件参数页直接由 ESP32 提供，经现有 HTTP→UART→PS 下发，不需要启动 Python，也不需要 USB 控制台。

需要更新本次 ESP32 应用和配套 Zynq PS 应用。**无需更新 bit/XSA、FSBL 或 BOOT.BIN**。
本次离线交付没有下载、烧录、启动扫描或使能高压。用户原有 VS Code 设置没有纳入本功能改动。

实时图像的显示设置仍需要 PC 服务，在 `esp32c61` 目录运行：

```powershell
python .\pc_tools\bmode_web_viewer.py --device-ip 192.168.3.27
```

打开控制台的“超声实时图像”，或本机 `http://127.0.0.1:8080/`。
PC 服务启动不自动上传，不启动扫描，不开启高压，也不代理硬件参数命令。

## 硬件配置步骤

1. 导入现成 JSON，可多选合并；同名类别由后导入的文件替换。任何一个文件无效时整次导入失败，不替换当前草稿。
2. 按类别修改表单或表格。每页最多 64 行；大表支持原始传输值曲线和热图预览，不将其数值冒充物理单位。
3. 勾选要下发的类别，点击“校验并预览命令”。全部已加载配置均须合法，未勾选类别也不能含非法内容。
4. 点击“应用选中参数”，确认停止扫描和关闭高压。系统先排空已接受上传，再进入配置事务。
5. 等待结果。成功后扫描、高压和上传全部保持停止，按需要在原控制台手动恢复。
6. PC 页面涉及角度映射时，停止接收，导入同一份配置并确认对应关系，然后开始接收。

不会隐式导入参考工程的默认表。新建表只生成浏览器编辑模板；多数系数模板为零，**不是可用成像配置**。
“本类别 JSON 编辑”需点击“校验并更新草稿”后才用于下发。
浏览器草稿和导出文件均不代表硬件已经应用；参数不写入 ESP32 NVS，硬件重启仍用 C 数组默认值。

### 支持的配置

| 类别 | 内容 / 深度 |
|---|---|
| AFE5832 | LNA 15/18/21 dB，PGA 21/24/27 dB，LPF 10/15/20/25 MHz，HPF 档位，低噪声/低功耗模式，四组 DHPF |
| AFE 原始寄存器 | GLOBAL/ADC/VCA/DTGC；8 位地址、16 位数据；保持写入顺序 |
| DTGC | 已准备的寄存器序列；兼容寄存器级 `profiles` 导入并展开为原始寄存器 |
| TX7332 | `tx7332_config_data`，128 个 32 位传输字，即 64 组地址/数据对 |
| 发射延时 | `delay_profile`，16384 字 |
| 解调 | `fdemod_sin`、`fdemod_cos`，各 8192 字 |
| 对数表 | `log_table`，1024 字 |
| 阵元位置 / 加窗 / FIR | `x_element`、`hamming`、`dfilter`，各 64 字 |
| 扫描时序 | `t_timing`，10 字 |
| 扫描角度 | `sin_beta`，64 字 |

BRAM 偏移单位是 **32 位传输字，不是字节**；算法系数自身的精度与有符号格式按原表定义。
AFE `input_impedance_ohm` 仅保留为说明，本接口没有对应寄存器写入。
低功耗工作模式与 PDN_GBL 全局掉电待机是不同功能；低功耗模式不接受 25 MHz LPF。

不提供 MATLAB、焦点、解调或 FIR 表生成。包含 ADC 时钟、深度、增益等计算参数的 DTGC JSON 明确拒绝，需先在外部转换为现成寄存器序列。
既有 Python DTGC 计算能力保持兼容，但不是网页导入过程的一部分。
VCA/DHPF 表单生成命令在前，原始寄存器在后；重复地址会在预览中提示，后写仍会覆盖前写，不自动去重。

### JSON 示例

以下仅用于说明文件结构；AFE 原始寄存器值应根据实际配置准备。文件导入本身不会发送任何命令。

```json
{
  "format_version": 1,
  "description": "我的 4 倍抽取配置",
  "afe5832": {
    "vca": {"lna_gain_db": 21, "pga_gain_db": 27, "lpf_mhz": 20,
            "lna_hpf_khz": 310, "power_mode": "low_noise"},
    "dhpf": {"groups": [{"group": 0, "enable": false,
                         "corner_code": 2, "round_enable": false}]},
    "raw_registers": []
  },
  "bram": {
    "t_timing": [6144, 7059, 10, 125, 3, 403, 6656, 915, 6144, 2]
  },
  "viewer": {"version": 1, "depth_mm": 120, "dynamic_range_db": 45,
             "brightness_db": 3, "contrast": 1, "noise_floor_db": -45}
}
```

可以仅包含选定类别。`viewer` 不产生任何硬件命令。
其他表使用 `bram` 对应名字和完整数组；TX 用 `tx7332.tx7332_config_data`。
DTGC 原始序列可放在 `afe5832.dtgc.raw_registers`（每项 `addr/data`），或直接放在 `afe5832.raw_registers` 中并注明 `map:"DTGC"`。
阵列长度、整数范围、未知执行字段及版本均校验；不兼容的 2048 点时序不会自动修改后下发。

### 回读、失败与取消

AFE 原始寄存器行和 TX 地址/数据行提供回读。AFE 回读也需要配置事务，所以会停流、停扫、关闭高压。
TX 回读只接受合法 10 位地址字，不把其他控制编码误当寄存器地址。
逐批最多 8 条，每条最多 8 个传输字，使用现有有界任务接口；预览只展示前 40 条，结果仅保留最近批次以控制浏览器开销。

第一条失败后停止后续写入，并尝试中止自己的事务；取消在当前批次完成后处理。
配置执行中“安全停止（关闭高压）”仍可用，复用既有优先关闭高压并停扫操作，同时取消后续参数批次。
**已执行的寄存器写入不能回滚。** 通信中断、任务丢失或回执不完整时报告结果未知，不自动重发参数，也不盲目发送新的中止命令。
结果未知后先查询 PS 状态；事务已结束才允许再次应用。关闭页面不会撤销已经接受的命令，既有 60 秒事务看门狗负责失联清理。
已知 `ESP-HTTP-001` SRAM/JSON 分配问题仍未修复；遇到 HTTP 500 应确认设备状态，不重复点击下发。

## 下采样与实际成像长度

原始点数固定 6144、每帧 64 条线。网页、Python、共享命令校验和 PS 都要求 `t_timing[0]`、`t_timing[8]` 为 6144；第 9 项只能为 0～4。

| 参数 | 倍率 | 每线输出点数 | 帧长 / B | 有效采样率 / MHz |
|---:|---:|---:|---:|---:|
| 0 | 1 | 6144 | 787456 | 25 |
| 1 | 2 | 3072 | 394240 | 12.5 |
| 2 | 4 | 1536 | 197632 | 6.25 |
| 3 | 8 | 768 | 99328 | 3.125 |
| 4 | 16 | 384 | 50176 | 1.5625 |

图像接收按 TCP/UDP 帧长和 64 条线头验证，不用配置草稿推测数据大小，不跨帧拼接。
PC TGC 以原始采样位置定义，抽取后按原始深度重采样；扫描转换使用表中实际采样率，保持声速 1540 m/s。
倍率变化清理旧图像并重置平滑。数据量减少不等于采集、传输和显示帧率必然等比例增加。

## PC 图像显示设置

- 动态范围 20～70 dB；亮度 −10～20 dB；对比度 0.5～2；噪声底 −60～−20 dB。
- TGC 开关、2～128 个 `[原始采样位置, dB]` 控制点，位置递增且覆盖 0～6143，增益 −24～24 dB。
- 灰度 LUT 256 个 0～255 整数，可编辑或导入数组/原参考 LUT 文本。
- 显示深度 10～188 mm。上限保留所有五档数据的插值余量。角度必须为严格递增的 64 项，范围 −89°～89°。
- 当前默认保留 ±45°、120 mm、TGC 开启、45 dB、亮度 +3 dB、对比度 1、噪声底 −45 dB和原灰度 LUT。

普通灰度设置可在接收期间应用，在处理线程的帧边界生效；深度/角度变更必须先停止接收。
冻结只影响浏览器画面；应用显示设置后等待新设置版本图像，不把旧画面标成新效果。

导入硬件配置时，PC 仅提取 `viewer` 和 `bram.sin_beta`，不会发送其他字段。
显式 `viewer.angles_deg` 优先；否则由 20 位有符号 Q18 的 `sin_beta` 解码角度并校验。必须确认文件确实对应当前硬件配置。
文件缺少角度时保留当前角度，不伪称已从硬件同步。抽取不由文件覆盖，始终由实际帧确认。
PC 设置仅驻留当前服务内存，可导出 JSON，重启服务恢复默认。

本机接口：

- `GET /api/viewer/settings` 返回 `settings`、`revision`、`applied_revision`、`image_revision`。
- `PUT /api/viewer/settings` 接受 `{revision, settings}`；整份设置需完整有效。
- 手工配置导入接受 `{revision, profile, confirm_geometry:true}`，其中 profile 只需含显示设置及角度表。
- 最大请求 32 KiB；修订号冲突或运行中变更几何返回 409，非法配置返回 400。
- 继续仅绑定回环地址并检查同源，不提供硬件命令代理。

处理队列仍最多两份载荷，最多 20 FPS；重建几何、映射及 PNG 编码在图像线程执行，不等待浏览器或文件保存，不延迟 TCP 完整帧 CRC 回执。
